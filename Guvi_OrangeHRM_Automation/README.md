# OrangeHRM Automation Testing Project

## Project Objective

This project automates the testing of the OrangeHRM demo web application using Selenium, Python, Pytest, and Page Object Model.

Application URL:

https://opensource-demo.orangehrmlive.com/

## Features Automated

- Login using multiple credentials from Excel
- Home page URL validation
- Login field validation
- Main menu validation
- Admin user search
- Forgot password validation
- My Info sub-menu validation
- Leave page validation
- Claim page validation
- Logout validation

## Tools Used

- Python
- Selenium WebDriver
- Pytest
- OpenPyXL
- Pytest HTML Report
- WebDriver Manager
- Allure Report

## Project Structure

pages - Page Object Model files  
tests - Test case files  
utilities - Reusable utilities  
testdata - Excel test data  
reports - HTML reports, Allure Reports 
screenshots - Failure screenshots  
logs - Execution logs
